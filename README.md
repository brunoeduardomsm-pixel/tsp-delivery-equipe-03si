## Sobre o projeto
Este repositório faz parte do TED "Aplicando o TSP em um projeto de software". A ideia é mostrar o TSP na prática, com planejamento em equipe, divisão de papéis, acompanhamento das tarefas e registro do que foi feito.

O produto é um **app de delivery de comida**, com foco em pedidos e entregadores. Seguimos o **Caminho A**: um protótipo de páginas em HTML e CSS.

## Objetivo da equipe
Entregar um protótipo com 4 telas funcionando no navegador, usando o TSP para organizar tarefas, papéis e acompanhamento do time.

## Como a equipe se organiza
- As tarefas ficam no quadro **Kanban** do GitHub Projects (A fazer, Fazendo, Em revisão, Feito).
- Cada tarefa é uma **Issue** com um responsável.
- As reuniões são registradas no arquivo `reunioes.md`.
- Cada integrante mantém a sua **planilha PSP**.
